# My First Web3

Simple Web3 project built with Solidity, Hardhat and ethers.js.

## Features

- Smart Contract
- Connect Wallet
- Ethereum Compatible
- Hardhat
- Deployment Script
- Unit Test

## Project Structure

contracts/
scripts/
test/
frontend/

## Install

npm install

## Compile

npx hardhat compile

## Test

npx hardhat test

## Deploy

npx hardhat run scripts/deploy.js
